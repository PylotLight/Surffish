# Surffish v0.1.6

A built-in Reading List, PIN and Touch ID quick unlock for "Bramble", and working blob: and data: links, plus fixes for the overlay sidebar, toolbar popovers and Bramble's pages.

## New

- **Reading List**: save pages to read later, separate from bookmarks. A toolbar button beside Bookmarks shows an unread badge and opens a popover with **Add This Page**, **Unread / All** filters, search, mark read/unread, remove and **Clear read items**. Pages can be added with ⇧⌘L, from the page, link and tab context menus, from the **Bookmarks** menu, or with ⌘K → **Add to Reading List**. Re-saving a page moves it back to the top as unread. When a saved page is an article, a Reader copy is kept on the device so it can be opened offline (⌥-click). Not available in private tabs (#140)
- **Quick unlock for "Bramble"**: Settings → **Integrations → Quick unlock for Bramble** sets up a 4–8 digit PIN, with optional Touch ID on supported Macs, to unlock the bundled "Bramble" password manager without retyping the master password. Bramble's own code and crypto are unchanged; the master password is stored encrypted and filled into Bramble's unlock form. By default the master password is required again after Surffish restarts. Setup is only offered once a Bramble vault exists (#138, #142)

## Fixed

- Links to page-made `blob:` and `data:` URLs (generated PDFs, CSVs and similar) now behave as in Chrome: they open in a new tab in the same session, render in the built-in PDF viewer, or download; a tab that only produced a download closes itself. Typing `blob:` or `data:` URLs in the address bar is still not supported (#147)
- "Bramble" auto-lock timeout changes now take effect immediately instead of only after a restart (#138)
- "Bramble" **Settings → Backups → Restore** and **Import** now open their pages, and the Bramble popup correctly detects the current site (#146)
- Extensions that open or focus an already open tab, such as Bramble's **Create your vault**, now bring that tab forward and close any covering panel such as Settings (#143)
- The overlay sidebar's blurred underlay now follows the width while resizing instead of jumping to full size, and the sidebar no longer stays stuck open after a lost hover, focus or drag (#148)
- The screenshot preview popover now closes itself after 20 seconds untouched; hovering, copying or saving keeps it open (#141)
- A popover opened right after a tab switch (Reading List, or the bookmark star after ⌘D) is no longer closed by the late tab-switch update (#149)

## Data and storage

- `surffish.db` schema v2 adds a `reading_list` table, migrated automatically from v1 with existing data intact. Removed items leave no page details behind and are purged after 30 days. Offline Reader copies stay on the device. Falls back to `reading-list.json` when the database is unavailable or `SURFFISH_STORE=json` is set (#140)
- Quick unlock settings are kept in `bramble-quick-unlock.json` in the profile (owner-only permissions); when it is persisted, the device key is protected by the macOS Keychain (#138)

## Performance

- The Reading List loads lazily and does not add work at launch (#140)

## CI

- New smoke tests for the Reading List, blob/data links, screenshot preview dismissal and the overlay sidebar; fixed a Reading List smoke flake (#140, #141, #147, #148, #149)

## Packaging

- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
