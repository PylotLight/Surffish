# Surffish v0.1.32

Surffish adds optional page and selected-text translation through Google Translate.

> This release ships on an Electron **beta** (45.0.0-beta.6).

## New

- **Page translation**: the page menu and right-click menu open a translated copy in a new tab while preserving the original. Local and private addresses are excluded. (#298)
- **Text translation**: selected text can be translated from the right-click menu, and the translation settings include a text box for pasted text. Source languages are detected automatically. (#298)
- **Target language**: the translation settings remember the preferred target language and keep it synchronized across browser surfaces. (#298)

## Data and storage

- Translation is online and only starts after a translation action. The page URL or selected/pasted text is sent to Google Translate and may appear in addresses and browsing history. Signed-in pages may not translate successfully. (#298)

## CI

- Unit coverage and an isolated-profile Electron smoke cover input validation, target-language persistence, cross-surface synchronization, translation tabs, toolbar bounds and context-menu actions. (#298)

## Packaging

- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release.
