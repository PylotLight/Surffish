# Surffish v0.2.0-beta.4

Surffish now has a continuous browser frame around the toolbar and sidebar, with live pages and New Tab displayed as inset cards. Pinned sites move more smoothly between the compact rail and expanded sidebar. This release updates Electron to 46.0.0-alpha.10.

## Added and improved

- **Integrated frame:** macOS uses native vibrancy for a continuous toolbar/sidebar surface. Supported Windows 11 22H2+ builds use Mica when Electron exposes the API; other configurations use a solid fallback. Appearance settings add a frame-transparency control for the macOS glass frame.
- **Inset page cards:** Live pages sit in opaque, rounded cards beside the docked sidebar or collapsed rail. New Tab is a rounded card on the same frame ground; with **Sidebar pushes page** enabled, the card moves aside as the sidebar opens, and the New Tab customization panel aligns to the card’s right edge.
- **Pinned-site rail:** Pins remain in one ordered cluster. The first pin stays anchored while the remaining pins glide smoothly as the sidebar collapses and expands.

## Dependencies and CI

- Electron `46.0.0-alpha.10`, Vite `8.3.8`, `@vitejs/plugin-react` `6.3.0`, and `tldts-experimental` `7.4.26`.
- Electron smoke coverage checks frame and page geometry, New Tab layout, sidebar reveals, and pin motion. Hosted Linux smoke setup now installs FFmpeg and retries package installation.

## Packaging

- Apple silicon macOS ZIP: `Surffish-0.2.0-beta.4-mac-arm64.zip`. The app is unsigned and not notarized; there are no Windows or Linux release assets. If macOS reports the app as damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release.
