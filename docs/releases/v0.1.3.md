# Surffish v0.1.3

Mostly a perf release, plus a split view fix. v0.1.2 was tagged but never got a GitHub release, so if you're coming from v0.1.1 see [v0.1.2's notes](v0.1.2.md) too.

## New
- Memory saver: under memory pressure the least recently used background tabs are discarded and reload when you open them. On by default (#98)

## Fixed
- Moving a split to a new window keeps focus on the pane you were on instead of jumping to the other one (#101)
- Closed windows no longer leak their toolbar/sidebar renderers (~118 MB each), and a failed surface load retries (#94)
- Bad input in update feed, search keyword and watcher settings returns an error instead of throwing (#100)
- The saved session file is cleaned up and kept private (0600) again at startup (#93)

## Performance
- First window shows before the adblock engine and extensions load (#96)
- Tab/state updates to the UI are batched per frame and sent as diffs, about 3x fewer IPC messages with 20 tabs (#95)
- Settings, Downloads, Bookmarks, Network, Diagnostics and archived tabs load on demand, so less JS runs at startup (#97)
- Main process loads the HTML parser, sql.js and Readability lazily (main bundle -26%) (#92)
- Site icons aren't re-fetched on every tab update anymore (#91)

## CI
- Every PR gets a perf check against its base (startup, bundle size, memory, IPC, leaks) and core Electron smokes run on macOS (#99)
- Faster Linux CI: fewer pods, parallel smokes, docs-only changes skipped (#90). Smokes fail for real now and have a hard timeout (#93, #100)
- The release workflow installs bun-only on the Mac runner (#102)

## Packaging
- Same as before: Apple-silicon zip only, unsigned and not notarized. If macOS says it's damaged, run `xattr -cr /Applications/Surffish.app` on a copy from the official release
