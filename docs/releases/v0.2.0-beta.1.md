# Surffish v0.2.0-beta.1

Surffish's first beta, built on the Electron 46 alpha, and the first pre-release on the beta channel.

## New

- **Beta channel**: the first pre-release, v0.2.0-beta.1, is published on the beta channel. Pre-releases are offered ahead of the latest stable, and the update check surfaces them when the beta channel is enabled.

## Fixed

- Clearing site data no longer asks the engine to clear WebSQL storage, which the Electron 46 engine no longer clears. Cookies, storage and cache are still cleared as before.

## Packaging

- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
