# Surffish v0.1.1

## New
- Sign in with Google through a native WebKit helper, with Bramble able to fill the login (#36)
- Drag tabs to reorder them (with a smooth animation), or use ⌥⇧↑ / ⌥⇧↓ from the keyboard (#37)
- A New Tab row sits under your last tab (#37)
- Settings got a rework: the gear opens and closes it, Esc or clicking a tab gets you out, close button moved to the right, and the layout is wider with bigger text (#37)
- New Tab world clocks now have a city search (Tampa, Seattle and friends) instead of raw time zones (#37)

## Fixed
- Bramble autofill clicks and copy-to-clipboard work again
- The Bramble autofill "Vault locked · Click to unlock" row now opens the unlock popup instead of doing nothing (#38)

## Packaging
- macOS release is now just the Apple-silicon DMG (no ZIP)
- Still unsigned and not notarized. If macOS says it's damaged, run `xattr -cr /Applications/Surffish.app` on a copy you got from the official release
