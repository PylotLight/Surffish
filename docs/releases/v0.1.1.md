# Surffish v0.1.1

## New

- Sign in with Google through a native WebKit helper, with Bramble able to fill the login (#36)
- Drag tabs to reorder them (with a smooth animation), or use ⌥⇧↑ / ⌥⇧↓ from the keyboard (#37)
- A New Tab row sits under your last tab (#37)
- Settings got a rework: the gear opens and closes it, Esc or clicking a tab gets you out, close button moved to the right, and the layout is wider with bigger text (#37)
- New Tab world clocks now have a city search (Tampa, Seattle and friends) instead of raw time zones (#37)
- Install Chrome Web Store extensions: paste a store link or ID in Settings → Integrations, or hit Add to Surffish on the store page. Modern for Hacker News is the first one verified (#46)
- ⌘⇧T reopens the tab you just closed (#48)

## Fixed

- The sidebar no longer collapses or jitters when you open or close a tab (#48)
- Bramble autofill clicks and copy-to-clipboard work again
- The Bramble autofill "Vault locked · Click to unlock" row (and passkey "Unlock & Use") now opens the unlock popup instead of doing nothing, dropping down from the Bramble icon (#38, #40, #42, #43)

## Packaging

- macOS release is just the Apple-silicon zip now, at about 117 MB with max compression and only English Chromium locales bundled (#49). The old DMG was about 320 MB and never opened ("not supported on this Mac")
- Still unsigned and not notarized. If macOS says it's damaged, run `xattr -cr /Applications/Surffish.app` on a copy you got from the official release
