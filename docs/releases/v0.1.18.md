# Surffish v0.1.18

Mini windows can now be thrown: letting go mid-drag sends a window gliding to a stop, and stacked windows hold steady when the main thread stalls.

> This release ships on an Electron **beta** (45.0.0-beta.4). Main tracks Electron betas; a daily check opens a bump PR when a new one is out.

## New
- **Throw with momentum**: letting go of a mini window mid-drag carries it on with friction until it stops. A throw eases into the screen edges and never leaves the window off-screen; a hard fling toward an edge tucks the window there. Stack followers and the Float header move in step with the thrown window, handles glide along their edge, and grabbing a gliding window stops it. Reduce Motion is respected. On by default under the **Throw with momentum** setting, with a ⌘K toggle. On macOS, throws work with the Float header (the default) and handle drags, not native Overlay or Push header drags (#220)

## Fixed
- **Mini window motion**: stacked windows no longer jump out of place or get moved twice when the main thread stalls. Slides, handle glides and the menu bar drop-in are timed from their first frame, with no catch-up ticks (#219)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
