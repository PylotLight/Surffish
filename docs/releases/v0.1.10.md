# Surffish v0.1.10

Surffish now runs on **Electron 45.0.0-beta.3** (Chromium 156). Tab switching is faster and main-thread stalls are fewer. Extensions talk to their service workers directly, and there's an experimental built-in AI for pages (off by default).

> This release ships on an Electron **beta**. Main now tracks Electron betas; a daily check opens a bump PR when a new one is out.

## New

- **Electron 45 beta**: Electron 44.5.1 → 45.0.0-beta.3. In our bench, tab switching went 49 → 37 ms, main-process long tasks 21 → 3, and memory with 30 tabs fell about 5% (#188)
- **About shows the engine**: Settings → About & updates lists the Electron and Chromium versions (#188)
- **Built-in AI (experimental, off by default)**: Settings → General → Built-in AI lets pages and extensions that use the Prompt API (`LanguageModel`) get answers from Surffish. Providers are a test echo or an OpenAI-compatible server on your own machine (LM Studio, Ollama, llama.cpp; loopback addresses only). Never in private tabs. When off, the API reports it's unavailable and nothing runs (#195)

## Improved

- **Extensions**: Web Store extensions' service workers now get navigation events and declarativeNetRequest state through Electron's service-worker preload instead of a hidden page per extension. Events arrive in 0–1 ms instead of 4–10 ms, a stopped worker is only woken for events it listens to, and `storage.onChanged` now fires in extension service workers. The hidden page stays as a fallback (#193)
- **Battery**: hidden helper views (page watchers, extension bridge, Glance header, tab overview, link status, screenshot overlay) can no longer hold wake locks, so a watched page playing media can't keep the Mac or display awake (#192)

## CI

- The Mac runner can install new packages again: Bun can't use the runner's SOCKS proxy, so `bun install` there now goes direct (#188)
- Daily Electron update check opens a bump PR (or a tracking issue) with the exact new version; never merged automatically (#191, #194)
- Smoke fixes for Electron 45 and a flaky certificates check (#188)

## Packaging

- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
