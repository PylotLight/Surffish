# Surffish v0.2.0-beta.6

A sidebar polish follow-up to [beta.5](https://github.com/PylotLight/Surffish/releases/tag/v0.2.0-beta.5), focused on the hover panel and its frame staying in sync with the page.

## Fixes

- **Collapsing drops the panel ghost:** Collapsing the sidebar no longer leaves an outgoing panel ghost behind while the rail settles (#327).
- **Labels clip during hover expansion:** Tab labels are clipped to the panel's edge while the hover panel expands, so text no longer spills past the sidebar onto the page (#328).
- **First-frame native hover reveal:** The native hover reveal starts on its first frame instead of a frame late, so the panel and its contents open together (#329).
- **macOS sidebar backdrop over pages:** The sidebar backdrop now lives in its own web contents view on macOS, so it sits correctly over WebContentsView pages (#330).
- **Waking tab under the pushed panel:** Clicking a sleeping tab while the hover panel is open no longer shows its snapshot at the unpushed spot with panel labels drawn over it. The snapshot is placed at the pushed page position and slides with the page card (#331).

## Dependency baseline

- No dependency changes since beta.4; see the [beta.4 notes](https://github.com/PylotLight/Surffish/releases/tag/v0.2.0-beta.4).

## Packaging

- Expected asset: Apple silicon macOS ZIP, `Surffish-0.2.0-beta.6-mac-arm64.zip`. The app remains unsigned and not notarized; there are no Windows or Linux release assets.
