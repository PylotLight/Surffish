# Surffish v0.2.0-beta.7

A sidebar and tab feel update on top of [beta.6](https://github.com/PylotLight/Surffish/releases/tag/v0.2.0-beta.6).

## Features

- **Resize push:** The hover panel can now resize the pushed page instead of overlapping it, with a new Sidebar animation setting (#332). The resize push re-lays out once and slides in between, so it stays smooth (#333).
- **Rail pins condensed:** Pinned tabs on the collapsed rail now show as the first pin plus a "+N" chip instead of an overlapping stack (#334).
- **Card-only swipe:** Back/forward trackpad swipes leave the page in place and only show the hover card. Settings › Appearance › "Swipe slides page" brings back the sliding page on macOS; it is off by default (#335).
- **Slept tab titles:** Sleeping tabs keep their real page title instead of showing only the hostname, and titles are saved with the session so they come back after a restart before tabs load (#336).

## Dependency baseline

- No dependency changes since beta.4; see the [beta.4 notes](https://github.com/PylotLight/Surffish/releases/tag/v0.2.0-beta.4).

## Packaging

- Expected asset: Apple silicon macOS ZIP, `Surffish-0.2.0-beta.7-mac-arm64.zip`. The app remains unsigned and not notarized; there are no Windows or Linux release assets.
