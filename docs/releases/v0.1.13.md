# Surffish v0.1.13

Surffish now lets you have up to six mini windows open at once, each with its own edge handle when tucked.

## New
- **Multiple mini windows**: every pop out (⌘⇧M, ⌘K, the tab menu or the Window menu) opens a new mini window and the ones already out stay out, up to 6 at a time. A 7th pop out shows a notice in the browser window asking you to return one first. New windows cascade a little toward the middle of the screen from the newest one so they don't land on top of each other (#203)
- **Stacked edge handles**: each mini window tucks on its own, with its own handle showing its page's icon. Handles tucked on the same edge spread out along it so they never overlap, and dragging one handle past another swaps their order (#203)
- **Show/hide all**: the global mini window shortcut (⇧⌘Space by default) and **Show/Hide Mini Windows** in ⌘K and the Window menu now act on all mini windows at once: if any are on screen they all hide (tucked ones tuck away), otherwise they all come back and the last one you used gets focus (#203)
- **Return one or all**: ⌘⇧M or the header button inside a mini window returns just that one to the browser. In ⌘K, "Return Mini Window to Browser" is now **Return All Mini Windows**, and with 2 or more open, ⌘K also lists Show, Tuck Away / Slide Out and Return commands for each window by title (#203)
- **Window menu**: lists each open mini window by title (checked = focused); clicking one brings it up and slides it out if tucked. Also adds **Return All Mini Windows** and **Show/Hide Mini Windows** (#203)
- Size, position and edge are remembered per window slot and per display. Your existing mini window position and edge carry over to the first window (#203)

## CI
- `test:electron-mini-window` and `test:electron-mini-window-dock` smoke tests cover several mini windows: cascading, the 6-window cap, toggle-all, return one and return all, and spread handles on a shared edge (#203)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
