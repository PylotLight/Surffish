# Surffish v0.1.30

read aloud lands as an experimental on-device voice that also reads PDFs, and mini windows get a new tab button and their own address field.

> This release ships on an Electron **beta** (45.0.0-beta.6). Main tracks Electron betas; a daily check opens a bump PR when a new one is out.

## New
- **Read Aloud (experimental, off by default)**: articles, a selection, or a page from any point read out loud by an on-device voice model (Phonon 31M via WebAssembly). text never leaves the machine. turn it on in Settings → Integrations → **Read Aloud**, which downloads the model once (~71 MB, hash-checked). 38 voices grouped by accent with a recommended set, speed 0.75–3×, and a tester right in settings (#290)
- **Read Aloud entry points**: page right-click → **Read Aloud** ▸ (Read Selection, Read from Here, Read Page, Pause/Resume, Stop), the Reader view **Listen** button, Reading List → **Listen**, ⇧⌘U to play/pause, and a toolbar player with prev/next, speed and voice while reading. the current sentence is highlighted in Reader view and on live pages (#290)
- **Read Aloud for PDFs**: the built-in PDF viewer and the PDF editor tab can be read with ⇧⌘U, ⌘K, or right-click → **Read Aloud** ▸ (Read Page, **Read from This Page**, Read Selection). headers, footers and page numbers are skipped, two-column pages read in order, and words split across lines are joined. scanned PDFs with no text say so (#291)
- **condensed context menu**: link menus get **Copy Link As** ▸ and **Save Link** ▸, the page's own items fold into a **Page** ▸ submenu when a link, image or selection is clicked, and extra tools move under **More Tools** ▸ (#290)
- **new tab in mini windows**: + or ⌘T opens a New Tab in the mini's tab strip in Tabs mode, or a new cascaded mini (same private state, window and Space) in Stack / Separate modes (#292)
- **mini window address field**: ⌘L opens a compact address field with the same suggestions as the toolbar omnibox, and it shows by itself on a New Tab. tucked and menu bar minis slide out while it's open, Esc restores what was typed and a second Esc hides it (#292)
- **compact mini New Tab page**: favourites and frequently visited, sized for a mini (#292)

## Fixed
- a reading paused for 10 minutes now stops on its own, so the engine can close and free its memory (#291)

## Performance
- read aloud costs almost nothing at startup while off (~15 KB across bundles). the engine runs CPU with 2 threads by default, stays a few sentences ahead instead of racing, and its window closes 3 minutes after the last reading, freeing ~400 MB. the PDF text reader loads only on the first PDF reading (#290, #291)
- the mini New Tab page is released when it isn't the active tab (#292)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
