# Surffish v0.1.29

pinned tabs finally keep the order they're given. cmd/ctrl+drag to rearrange pins and favourites, and new pins go on the end. also moves to electron 45.0.0-beta.6.

> This release ships on an Electron **beta** (45.0.0-beta.6). Main tracks Electron betas; a daily check opens a bump PR when a new one is out.

## New
- **reorder pins with cmd/ctrl+drag**: hold Cmd (Ctrl on windows/linux) and drag a pinned tab or favourite along the strip to move it. other pins slide out of the way, the dragged pin doesn't open, and Esc cancels. a plain drag still does nothing, so pins can't get shuffled by accident. pinned tabs and favourites each reorder among their own kind (#285)
- **Move Pin Left / Move Pin Right**: in the pinned tab's context menu, a no-drag way to reorder. each is greyed out at its end of the strip (#285)

## Fixed
- pinned tabs keep the order they're given instead of showing in whatever slot each tab happened to sit in the tab list (which often looked sorted). new pins now append to the end of the strip. order survives restarts and existing pins keep their current order, no migration (#285)

## Packaging
- Electron 45.0.0-beta.6, tldts-experimental 7.4.19 (#286)
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
