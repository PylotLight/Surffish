# Surffish v0.1.28

bramble pairing is way less fiddly now, scan the qr from the phone app instead of typing the code.

## New
- **scan qr on join a device**: the bramble join form has a "Scan QR" button that fills the pairing code from the phone app's qr. there's an optional "Scan password QR" too. camera access is only allowed for the bramble extension, nothing else gets it (#283)

## Fixed
- bramble setup tab closes itself once a vault is created or joined, no more leftover tab (#283)

## CI
- fixed flaky toolbar overflow + screenshot hover smokes on linux B (#282)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
