# Surffish v0.1.23

Full PDF form support in the built-in PDF editor: fill any form (including its calculations), sign signature fields, keep saved signatures, and add new form fields to any PDF. Plus a tiny launcher so Surffish runs with `npx @pylotlight/surffish` or `bunx @pylotlight/surffish`. Ships on Electron 45.0.0-beta.5.

> This release ships on an Electron **beta** (45.0.0-beta.5). Main tracks Electron betas; a daily check opens a bump PR when a new one is out.

## New
- **PDF forms**: the built-in PDF editor fills every field type (text, multiline, comb, password, date, checkbox, radio, lists, dropdowns with type-or-pick) and runs the form's own scripts, so formatting, validation and calculated totals work. Reset form, required fields outlined (empty ones flagged on Save), Tab and ⇧Tab follow the form's order across pages, and Flatten on save is available. Save writes back to the file picked the first time; Save As always asks. Pure XFA forms render with a notice (#260)
- **Saved signatures**: signature fields show a "Sign here" overlay and the signature is fitted to the field. Signatures and initials can be drawn, typed or uploaded as an image, and saved for next time, encrypted with the macOS keychain. Without OS encryption they stay for the session only (#260)
- **Add form fields**: a **Fields** tool group places text, paragraph, checkbox, radio group, dropdown, date (with date picker) and signature fields on any PDF, including ones with no form. Fields can be renamed, marked required or read-only, given defaults and choices, moved, resized and deleted, all undoable (#260)
- **Edit PDF on page-made PDFs**: **Edit PDF** now works on PDFs a page creates itself (`blob:` and `data:` links); **Back to viewer** returns to the original tab (#260)
- **Run with npx / bunx**: `npx @pylotlight/surffish` or `bunx @pylotlight/surffish` downloads the matching release once, verifies its SHA-256, caches it in `~/.cache/surffish` and opens it; later launches are instant and work offline. `--latest`, `--path`, `--clear-cache` and `--no-launch` are available. Apple silicon Macs only. The npm package is published from the release workflow with npm trusted publishing once it is enabled (#259)

## Fixed
- **PDF form layout**: form inputs no longer drift slightly off the drawn page, and filled date fields are no longer saved empty (#260)

## Performance
- The PDF editor's WebAssembly modules and form sandbox ship brotli-compressed, keeping the app download small (#260)

## CI
- New `cli` job runs the launcher's tests and smoke runs; new PDF forms smoke test in lane C (#259, #260)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
