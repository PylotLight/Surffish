# Surffish v0.2.0-beta.10

Surffish now signs in with Touch ID, offers an opt-in Cloudflare rewrite, and opens each New Tab tile at its exact bookmarked page.

## New

- **Touch ID sign-in**: a native WebAuthn PRF handler lets "Bramble" authenticate with Touch ID instead of a password.
- **Cloudflare round-host rewrite**: an opt-in rewrite that routes Cloudflare traffic through a round host, off by default.

## Fixed

- A New Tab (and mini window) favourite tile now opens its exact bookmarked URL instead of the site's origin, so a bookmarked "Google Maps" page opens that page rather than google.com.

## CI

- Updated the runtime to Electron 46.0.0-alpha.12 (#344).

## Packaging

- Still unsigned and not notarized. If macOS says it's damaged, run `xattr -cr /Applications/Surffish.app` on a copy you got from the official release.
