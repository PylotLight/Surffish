# Surffish v0.1.4

Scrolling screenshots, multi-select tabs, and a few UI fixes, including the address bar getting stuck on an old URL.

## New

- Scrolling screenshot: ⌘⇧S → **Scrolling** (or `S`), or **Scrolling Screenshot** in the ⌘K palette. Mark where it starts, scroll the page (or hit Auto-scroll), then press Enter or click where it should end, and you get one tall image in the usual preview (Copy / Save… / Annotate). Fixed and sticky headers show up once, and pages with their own inner scroller work too. Main frame only, up to 16,384 device px tall (#111)
- Multi-select tabs in the sidebar: Cmd-click toggles, Shift-click picks a range. Right-click the selection to group, add to a group, pin, move to a new window or close them all, or press ⌘G to group them (#112)

## Fixed

- The address bar no longer gets stuck on an old URL (like `/auth` after a login) once you click into the page or an extension popup. It follows redirects and in-page navigation again, and still keeps anything you're halfway through typing (#113)
- Waking a sleeping tab: the loading spinner starts turning straight away instead of sitting still for about a second (#114)
- The site menu (globe), downloads, extensions, bookmarks and star popovers close when you click the page, the sidebar or another app, or press Esc, instead of only when you click their button again (#114)

## CI

- macOS smokes run in a hidden mode where windows never actually show up on screen, so the Mac runner can be used while CI runs (#110)

## Packaging

- Same as before: Apple-silicon zip only, unsigned and not notarized. If macOS says it's damaged, run `xattr -cr /Applications/Surffish.app` on a copy from the official release
