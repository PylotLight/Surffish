# Surffish v0.1.11

Surffish adds a mini window: pop any tab out into a small window that floats above other apps, then put it back without reloading.

## New
- **Mini window**: **Pop Out to Mini Window** (tab right-click menu, ⌘K, **Window** menu, or ⇧⌘M) moves a tab into a small frameless window that stays above other apps, including full-screen apps and across Spaces, for an AI chat, a video or docs while working elsewhere. **Return to Browser** (the header's return button, ⌘K, **Window** menu, or ⇧⌘M again) moves it back. The page moves both ways, so nothing reloads and typed text, scroll position and playing media are kept (#198)
- **Mini window header**: a draggable header with Back, Reload, Return and Close appears when the pointer nears the top edge and hides when it leaves. The window is resizable, snaps into a screen corner, and remembers its size and position per display (#198)
- **Mini window settings**: Settings → **General** → **Mini window** sets a default page, a global toggle shortcut (⇧⌘Space by default; record a new one or clear it) and the window's opacity. With a default page set, the shortcut opens it in the normal profile, so signed-in sites stay signed in; otherwise it pops out the current tab. A shortcut already used by Surffish or another app is refused and Settings says why (#198)

## Performance
- A tab in the mini window counts as on screen: it is never put to sleep, discarded or auto-archived. Links opened from it go to a browser window (#198)

## CI
- New `test:electron-mini-window` smoke test in lane A (#198)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
