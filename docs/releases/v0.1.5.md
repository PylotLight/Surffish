# Surffish v0.1.5

Profiles now live in a SQLite database, screen sharing works, extensions built on declarativeNetRequest (like "I still don't care about cookies") are supported, and there's a built-in feed reader. Plus a batch of UI and performance fixes and a smaller download.

## New
- **Feeds**: a built-in RSS/Atom/JSON feed reader under Settings → **Integrations → Feeds** (the Extensions section is now Integrations, with Extensions and Feeds tabs). Add feeds by URL, from the current site (⌘K → **Add Feed from This Site…**), or from a GitHub repo (releases, commits, tags or Actions runs). Includes unread counts, mark all read, and per-feed interval, pause and notification settings. Nothing runs in the background unless at least one feed is followed (#120)
- **Screen sharing**: "Share screen" in Meet, Zoom web, Discord, Slack and similar sites previously failed. On macOS 15+ the system picker is used (as in Safari); elsewhere a chooser offers the current tab, screens and other windows. If Screen Recording permission is off, Surffish explains this and offers to open System Settings (#124)
- **declarativeNetRequest extensions**: extensions that rely on declarativeNetRequest rules and webNavigation now work. For example, "I still don't care about cookies" installs and hides cookie banners instead of being rejected (#127)
- **Page watchers toggle**: Settings → General → Page Watchers → **Enable page watchers**. On by default; when off, the watcher code is not loaded (#130)
- A small easter egg: triple-click the Surffish logo in the top right (#123)

## Fixed
- Toolbar popovers (site menu, downloads, extensions, bookmarks, History) now close on an outside click, Esc, tab switch or leaving the window. They size to their content ("Manage extensions" is no longer cut off) and text is larger and easier to read (#123)
- Switching tabs and quickly pressing ⌘Y no longer opens and immediately closes History (#131)
- Paused media in a background tab stays in macOS Now Playing so media keys can resume it; sleeping tabs, the memory saver and auto-archive no longer close paused media tabs (#116)
- Sidebar hover: the blur/tint and the panel now animate together. Back/forward swipes need a clearer sideways gesture, reducing accidental navigation. Fewer page flashes on tab switch and smoother settings/sidebar transitions. Reduce Motion is respected (#125)
- ⌘K or typing in the address bar right after a window opens no longer loses focus (#117)
- Opening a URL in a new tab (⌘K, bookmarks → Open in New Tab) no longer briefly shows address bar suggestions (#121)
- Fixed a "Could not save … database is not open" error on quit; pending saves are written before the database closes (#136)

## Data and storage
- History, windows/tabs, bookmarks, preferences and Spaces are now stored in a single SQLite database in the profile (`surffish.db`), using the runtime's built-in SQLite. Saves write only what changed, and windows, tabs and bookmarks have stable IDs in preparation for sync (#119, #122, #132, #133, #134)
- Migration is automatic and non-destructive: existing JSON files are imported on first launch and continue to be written alongside the database for now, so older builds can still open the profile. If the database can't be opened, Surffish falls back to the JSON files. Set `SURFFISH_STORE=json` to force the previous behaviour
- Clearing history removes the rows, the database change log and the WAL file, leaving no trace of cleared pages

## Performance
- Release zip is ~2.4 MB smaller and app.asar is roughly half its previous size (React was bundled twice, plus dependency sourcemaps) (#118)
- Faster launches after the first: the main process reuses V8's compile cache (`~/Library/Caches/Surffish/node-compile-cache`; set `SURFFISH_NO_COMPILE_CACHE=1` to disable) (#126)
- Fewer redundant disk writes at startup and quit (#128), and fewer toolbar IPC messages when opening tabs (#121)

## CI
- Fixed or instrumented flaky tests and smoke checks, and reduced noise in the performance check (#117, #135, #136)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
