# Surffish v0.1.5

A big one. Your profile moved into a proper database, screen sharing works, I still don't care about cookies works, there's a feed reader now, and a pile of UI and perf fixes. Smaller download too.

## New
- Feeds: a built-in RSS/Atom/JSON feed reader under Settings → **Integrations → Feeds** (the old Extensions section is now Integrations, with Extensions and Feeds tabs). Add a feed by URL, from the site you're on (⌘K → **Add Feed from This Site…**) or from a GitHub repo (releases, commits, tags or Actions runs). Unread counts, mark all read, per-feed interval/pause/notify. Nothing runs in the background if you don't follow any feeds (#120)
- Screen sharing works now. "Share screen" in Meet, Zoom web, Discord, Slack etc used to just fail. On macOS 15+ you get the system picker (same as Safari), elsewhere a small chooser with This tab, your screens and other windows. If Screen Recording permission is off it tells you and offers to open System Settings (#124)
- Extensions that use declarativeNetRequest rules + webNavigation actually work, eg **I still don't care about cookies** installs and hides cookie banners instead of being refused (#127)
- Settings → General → Page Watchers → **Enable page watchers**. On by default; turn it off and the watcher code never even loads (#130)
- Triple-click the Surffish logo top right. You'll see (#123)

## Fixed
- Toolbar popovers (site menu, downloads, extensions, bookmarks, History) close on any click outside, on Esc, when you switch tabs or leave the window. They size to their content (Extensions no longer cuts off "Manage extensions") and the text is actually readable now (#123)
- Switching tabs then hitting ⌘Y fast no longer opens and instantly closes History (#131)
- Paused YouTube/music in a background tab stays in macOS Now Playing, so media keys can resume it. Sleeping tabs, the memory saver and auto-archive were closing paused tabs (#116)
- Sidebar hover: the blur/tint and the panel slide in and out together instead of the tint popping in first. Back/forward swipes need a clearer sideways swipe, so they don't fire by accident. Fewer page flashes on tab switch, smoother settings/sidebar motion. Reduce motion makes it snap (#125)
- ⌘K or typing in the address bar right after a window opens no longer loses focus (#117)
- Opening a URL in a new tab (⌘K, bookmarks → Open in New Tab) no longer flashes the address bar suggestions first (#121)
- No more "Could not save … database is not open" when quitting; pending saves land before the database closes (#136)

## Your data
- History, open windows/tabs, bookmarks, preferences and Spaces now live in one SQLite database in your profile (`surffish.db`), using the SQLite built into the runtime. Saves only touch what changed instead of rewriting whole files, and every window/tab/bookmark gets a stable id so sync can happen later (#119, #122, #132, #133, #134)
- Nothing is lost on the way: on first launch it imports your existing JSON files, and keeps writing them alongside for now, so an older build still opens your profile fine. If the database can't open it falls back to the JSON files. `SURFFISH_STORE=json` forces the old behaviour if anything goes weird
- Clearing history/site data deletes from the database too (no leftover change log of what you visited)

## Performance
- Release zip is ~2.4 MB smaller and app.asar is about half the size (React was shipped twice, plus dependency sourcemaps) (#118)
- Faster launches after the first one: the main process reuses V8's compile cache (`~/Library/Caches/Surffish/node-compile-cache`; `SURFFISH_NO_COMPILE_CACHE=1` turns it off) (#126)
- Fewer redundant disk writes at startup and quit (#128), fewer toolbar IPC messages when opening tabs (#121)

## CI
- Lots of flaky tests and smokes fixed or made to say exactly where they got stuck, perf check is less noisy (#117, #135, #136)

## Packaging
- Same as before: Apple-silicon zip only, unsigned and not notarized. If macOS says it's damaged, run `xattr -cr /Applications/Surffish.app` on a copy from the official release
