# Surffish v0.1.19

A redesigned Settings, zoom in Glance, an address bar that lets you edit a suggestion before you go, and a menu bar popout that stays put. Tabs with muted autoplay video no longer show a speaker or stay awake for hours.

> This release ships on an Electron **beta** (45.0.0-beta.4). Main tracks Electron betas; a daily check opens a bump PR when a new one is out.

## New

- **Zoom in Glance**: pinch, ⌘+ / ⌘− / ⌘0 and Ctrl+scroll now zoom the page in a Glance instead of the tab underneath. Zoom is saved per site and kept when you promote the Glance to a tab (#226)

## Improved

- **Settings, redesigned**: denser grouped rows, sticky category headers with a jump list, a search field (press `/` to focus it), and collapsible groups for the Mini window settings (#223)
- **Address bar suggestions**: arrow keys or Tab fill the highlighted suggestion's full URL into the bar so you can edit it before pressing Enter. Esc restores what you typed, and Tab / Shift+Tab now step through the suggestions. The suggestion's URL line is bigger and higher contrast, with the host in bold (#224)
- **Menu bar popout**: the tab strip is now an always-on slim strip with the tabs plus ⋯ / Pin / Close. Nothing slides in or reflows on hover (#225)

## Fixed

- **Mini window tucked to the top edge**: no strip is left behind in the menu bar, the handle sits under the menu bar, and header drags stop below it (#222)
- **Tab speaker**: the speaker icon only shows while a tab is actually audible. Muted autoplay video (X, Instagram and news timelines) no longer lights it up (#227)
- **Tab sleep and muted autoplay**: tabs whose only media was muted autoplay video are no longer kept awake for six hours. Tab sleep, the memory saver and auto-archive now only hold a tab for media that was actually heard. Music and podcasts you paused still keep their Now Playing session as before (#228)
- **Reading List**: saving a page again right after another save now always moves it back to the top (#230)

## Packaging

- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
