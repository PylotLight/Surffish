# Surffish v0.1.17

Surffish moves up to **Electron 45.0.0-beta.4** (Chromium 156.0.8078.36), and mini windows stop stuttering when a slide starts right after the last one ended.

> This release ships on an Electron **beta**. Main tracks Electron betas; a daily check opens a bump PR when a new one is out.

## Improved
- **Electron 45.0.0-beta.4**: Electron 45.0.0-beta.3 → 45.0.0-beta.4, with Chromium 156.0.8078.36 and the upstream beta fixes (#213)
- **Mini window motion**: when the frame loop restarts from idle, its first frame now waits a full frame. Before, a slide starting within about a frame of the last one could land its first frame on top of its starting position, giving a duplicate step. This shipped in v0.1.16 but missed its notes (#216)

## CI
- The screenshot smoke's hover-hold check no longer races the preview's idle countdown on a busy runner (#217)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
