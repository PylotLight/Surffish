# Surffish v0.1.33

Surffish moves to Electron 45.0.0 stable, translates pages in place instead of opening a Google Translate tab, and adds an optional Maple Mono interface font.

> This release ships on Electron **45.0.0 stable**.

## New
- **In-place page translation**: Translate page now rewrites the readable text in the current page, with a small status panel and a **Show original / Cancel** button that restores the original text without reloading. Navigating away or starting a new translation cancels stale work (2e12165)
- **In-place selection translation**: Translate Selection shows the result in a small in-page panel instead of opening a new tab (2e12165)
- **Settings → Languages**: the translation target language moved to its own Languages settings page (`surffish://settings?section=languages`) (2e12165)
- **Interface font** (experimental): Settings → Appearance can switch Surffish's toolbar, sidebar and built-in pages to the bundled Maple Mono font. Websites are not affected; System stays the default (1090789)

## Data and storage
- Only a requested snapshot of readable text is sent to Google, without site cookies. Form values, editable fields, hidden text and code blocks are excluded, and local/private addresses are not translated. Provider output is applied as text only, never HTML (2e12165)
- Translation uses Google's keyless web endpoint, which may be rate-limited or change without notice. It covers the main document only (not frames, PDFs or shadow roots), large pages may be partially translated, and newly loaded content needs another request. The explicit Open in Google Translate fallback still opens a separate tab and shares the page URL (2e12165)

## Dependencies
- Electron 45.0.0 stable (from 45.0.0-beta.6) (#300)

## CI
- The translation smoke covers in-place page/selection translation, original text restoration, field exclusions and provider failures; a new UI font smoke covers the font preference (2e12165, 1090789)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release.
- Maple Mono v7.9 (SIL Open Font License 1.1) is bundled with its license notice (1090789)
