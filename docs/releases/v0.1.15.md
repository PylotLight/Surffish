# Surffish v0.1.15

The mini window header no longer covers the page. By default it now floats in its own strip just above the window.

## New

- **Mini window header**: a new setting in Settings → General → Mini window (next to grouping), also in the Window menu and ⌘K. Switching is live and nothing reloads. Your existing settings start on Float above (#209)
- **Float above** (the default): the header and tab strip sit in their own panel attached to the top edge of the mini window, outside the page, so a site's own nav bar is never covered. It moves, hides and closes with the window, and dragging it drags the window (merge, dock and corner snap still work on drop). Near the top of the screen or docked to the top it flips below the window; with no room either side it falls back to Push content (#209)
- **Push content**: the header stays inside the window and the page moves down under it while it shows, keeping your scroll position (#209)
- **Overlay**: the header slides over the page, the same as v0.1.14 (#209)
- Header buttons show their hint where the title is instead of a native tooltip, which used to land on top of the tab strip (#209)

## CI

- New `test:electron-mini-window-header` smoke test covers settings migration, the floating panel's position against the page, hover and hide, drag by header, flipping below near the top, the push fallback, tabs and merges with the floating header, live switches to Push and Overlay, and that nothing is left behind (#209)
- The Firefox bookmark import test gets a 30s timeout, since it hit the 5s default on a slow runner (#209)

## Packaging

- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
