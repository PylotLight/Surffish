# Surffish v0.1.20

A Customize panel on the New Tab with clock display options and weather on its own line, Settings as a tab, tab drag and drop for mini windows, and a lighter, faster ad filter and idle footprint. Ships on Electron 45.0.0-beta.5.

> This release ships on an Electron **beta** (45.0.0-beta.5). Main tracks Electron betas; a daily check opens a bump PR when a new one is out.

## New
- **Customize the New Tab in place**: a gear next to the photo buttons opens a side panel with every New Tab setting (page, layout, background, clock, world clocks, weather), applied live to the page behind it. Weather now has city search with saved coordinates, a choice of provider (Open-Meteo, MET Norway, wttr.in, OpenWeather with an API key) and an approximate-location option, and the icons' vertical position range covers the whole page (#239)
- **Clock display options**: Auto / 12-hour / 24-hour, AM/PM, seconds, date formats, clock size and position sliders, weight and digit style, world clock time difference and "Tomorrow"/"Yesterday", and a greeting. Available in the Customize panel and Settings → **New Tab** (#240)
- **Weather on its own line**: the New Tab weather sits on a centred line under the clock and date, scales with the clock size and moves with the clock position. Settings → **New Tab** → Weather → **Position** can put it in the top-right corner instead (#245)
- **Settings as a tab**: Settings opens as a tab (⌘/Ctrl+,, the gear, ⌘K) and closes like any other tab. A new **Sites** view lists sites with their own settings, and the address bar site menu shows this site's switches inline with a link to **All site settings** (#243)
- **Mini window tab drag and move**: reorder tabs along a mini window's strip, drop a tab onto another mini window at the slot under the pointer, drag a tab back to the sidebar or from the sidebar into a mini window, Esc to cancel, and keyboard shortcuts to move, split and merge. Return to Browser puts a tab back where it came from (#238)

## Fixed
- **New Tab weather**: requests now go through Chromium's network stack, so the proxy, network rules, system proxy and DNS settings apply, and errors name the real cause instead of "Can't reach". Open-Meteo's forecast model is selectable, with a fallback when a model has no data (#241)
- **Menu bar popout and Spaces**: opening the menu bar popout or a mini window no longer activates Surffish or jumps to the browser window's Space (#242)
- **Menu bar popout strip**: no longer flashes while typing in pages that update their URL on each keystroke (#236)
- **Address bar**: typed text is no longer overwritten when a navigation update arrives mid-keystroke (#232)

## Performance
- **Ad filter**: filter lists compile in a separate utility process instead of blocking the main thread, and the compiled engine cache is zstd-compressed on disk (9.0 MB to 3.8 MB) (#231, #235)
- **Tab Overview**: its renderer is only preloaded once the overview has been used on the profile, saving a process per window (#234)
- **Mini windows**: an idle, hidden mini window header releases its renderer after 30 seconds and is recreated when the pointer returns (#237)
- Electron 45.0.0-beta.5, electron-vite 6, Vite 8.3.4 and React 19.3.1 (#244)

## CI
- Footprint probe for per-process memory, launch peak and main-thread blocking (#233)
- Lane A Glance and omnibox-fill smoke races fixed (#232)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
