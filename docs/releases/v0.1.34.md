# Surffish v0.1.34

Surffish adds managed SSH tunnels and live activity details for a shared SOCKS5 endpoint.

## New

- **Managed SSH tunnels**: Settings → **Connection → SOCKS5 proxy** accepts an OpenSSH host alias from `~/.ssh/config` or `user@host`; aliases can be discovered from the local SSH configuration. Surffish starts and stops the tunnel with the browser, shows connection status, and exposes it through a configurable shared SOCKS5 port. (cd804c9, d86295c, 2c5db11, 01d3dd2)
- **Network Helper activity**: General Settings shows active connections, live upload/download rates, and totals for the shared SOCKS5 endpoint. (1269897, 90b1530)

## Fixed

- Network Helper activity now refreshes in General Settings, and traffic samples are bounded instead of accumulating stale data. (3b6d591, 55f2f2e)

## Data and storage

- The SSH host alias and shared SOCKS5 endpoint settings are saved with browser preferences; tunnel connections use the system OpenSSH configuration and agent. (cd804c9, 01d3dd2)

## CI

- Added Bun formatter checks and made security source guards independent of formatting. (91761b7, 55f2e6b)

## Packaging

- Apple silicon zip only, unsigned and not notarized. If macOS reports the app as damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release.
