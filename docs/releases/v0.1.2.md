# Surffish v0.1.2

Big one. Most of the roadmap's table stakes plus a pile of power-user stuff.

## New

- Find in page, per-site zoom, more tab/nav shortcuts, middle-click to close tabs, link hover status, and Copy Clean Link (strips tracking params) (#58)
- Private tabs: in-memory session, nothing saved to history, session or favicons, proxy and adblock still enforced (#57)
- Multiple windows: New Window / New Private Window, move or tear tabs out to another window, all windows restored on relaunch (#78)
- Split view: two tabs side by side with a draggable divider, moves and tears out as one (#79)
- Tab groups: named, coloured, collapsible groups in the sidebar, drag tabs in and out or drag a whole group to another window (#81)
- Spaces, off by default (Settings → Enable Spaces): named sidebar spaces with their own tabs and pins, Ctrl+1..9 to switch, optional per-space partition and proxy (#80)
- Command palette (⌘K) with tab search (⌘⇧A), custom search keywords and !bangs like `!yt`, `!gh`, `!npm` (#67)
- Bookmarks: folders, star popover, bookmark manager, import from other browsers and export. Bookmarks live in a toolbar dropdown now, with an optional bookmarks bar (⌘⇧B, off by default) (#70, #83)
- Tab auto-archive, off by default: idle tabs go to an Archived list you can search and restore; also Close Duplicate Tabs and switch-to-open-tab (#72)
- Screenshot tool (⌘⇧S): region, visible area or full page, with copy, save and annotate (#73)
- Reader view (⌘⌥R) and page watchers that check pages in the background and notify you when they change (Settings → Watchers) (#77)
- Per-site proxy routing with named SOCKS5 proxies and a per-proxy kill switch (#76)
- Network inspector tools: HAR export, copy as cURL / fetch, replay, mock and override rules. The inspector is opt-in now, off by default (#55, #56, #76)
- Built-in PDF editor: annotate, sign, fill forms, reorder and delete pages (#61)
- Set Surffish as your default browser; external links and files open in it, and inline PDFs save and print through the built-in viewer (#59)
- Copy Image in the context menu, or Option/Alt+click an image to copy it (#63)
- Update notifications: checks GitHub releases on launch and every 6h, with skip / remind later (#64)
- Safety pack: crashed or hung tab recovery, Clear Browsing Data (⌘⇧⌫), Forget This Site, site data controls, HTTPS-only mode (off by default), proxy kill switch (#66)
- Diagnostics task manager (Shift+Esc) showing per-tab CPU and memory (#68)
- Dev builds use their own "Surffish Dev" profile, so they run next to the release app (#65)
- UI polish: settings split into General / New Tab / Extensions / This site / Network, extension overflow menu, reworked downloads popup and page, tab audio mute indicator (#53)

## Fixed

- Spellcheck suggestions show up on macOS again (#66)
- Sites can always copy to the clipboard; reading it is a per-site toggle, and any blocked permission shows a notice instead of silently doing nothing (#62)
- Plain clicks on `target=_blank` links open a new tab instead of doing nothing (#71)
- Address bar no longer locks up on pages with drag-region CSS; F6 / Alt+D / ⌘L focus it (#60)
- Address bar suggestions show site favicons (#74)
- Cancelled or superseded loads don't flash an error anymore, and real load failures get a friendly error page (#82)
- Overlay sidebar is readable over live pages (native macOS blur) and matches the New Tab sidebar size exactly (#83, #84)
- WebRTC no longer leaks your real IP around the proxy (#58)

## Performance

- Background tabs are actually hidden and throttled, and invisible overlay blurs are gone, so idle GPU use drops a lot (#68)
- Network capture only starts once you open the Network view, disk writes are batched, renderer is minified (#54)

## Packaging

- Same as before: Apple-silicon zip only, unsigned and not notarized. If macOS says it's damaged, run `xattr -cr /Applications/Surffish.app` on a copy from the official release
