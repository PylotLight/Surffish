# Surffish v0.1.21

Faster address bar and restore: a sure history or bookmark hit is preloaded so Enter shows it almost instantly, and restored tabs show their last picture while they load. Plus a weather size slider and multi-day forecast on the New Tab, and a steadier menu bar popout strip. Ships on Electron 45.0.0-beta.5.

> This release ships on an Electron **beta** (45.0.0-beta.5). Main tracks Electron betas; a daily check opens a bump PR when a new one is out.

## New
- **Weather size and forecast**: Settings → **New Tab** → Weather (and the Customize panel) gains a **Weather size** slider (50–250 %) and a **Forecast** setting: Current only (default), Today (high/low and rain chance), or 3 / 5 / 7 days. wttr.in shows up to 3 days and OpenWeather up to 5 (#249)

## Fixed
- **Menu bar popout strip**: no longer blinks while a streaming or single-page app loads. Favicons stop flip-flopping on every in-page navigation, and the strip only updates the chips that changed (#248)

## Performance
- **Address bar prerender**: when what you typed exactly matches a History, Bookmark or Pinned site, Surffish loads it out of sight in the tab's own session and swaps it in on Enter (about 430 ms to 40 ms to first paint in testing). Back history is kept. Never for private tabs, on battery, under memory pressure, or for sign-out, checkout or download-looking links (#252)
- **Instant restore**: tabs restored after a restart show their saved picture straight away instead of a blank page while the site loads. Pictures are stored in the profile (48 MB / 7 day cap, never for private tabs), removed when the tab closes, and cleared with Clear Browsing Data (#253)

## Development
- Unpackaged macOS dev runs use a mock keychain, so the "Surffish Dev Safe Storage" keychain prompt no longer appears; set `SURFFISH_REAL_KEYCHAIN=1` to test the real keychain. Packaged builds are unchanged (#251)
- Manual **windows build** workflow for unsigned, ad hoc Windows zips (x64 / arm64) as build artifacts. Not part of releases (#247)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
