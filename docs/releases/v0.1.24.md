# Surffish v0.1.24

A small one for the npx / bunx launcher: it can now clean up after itself with `--uninstall`, and the npm page is just the user docs. Also the first release where the release workflow publishes `@pylotlight/surffish` to npm itself. Ships on Electron 45.0.0-beta.5.

> This release ships on an Electron **beta** (45.0.0-beta.5). Main tracks Electron betas; a daily check opens a bump PR when a new one is out.

## New
- **Launcher uninstall**: `bunx @pylotlight/surffish --uninstall` (or `npx`) deletes the launcher's download cache (`~/.cache/surffish`), which holds the app, then prints what's still on disk and how to remove it. It refuses to run while Surffish is open (#268)
- **Remove everything**: `--uninstall --all` (or `--purge`) also deletes Surffish's own data: profile, caches, preferences, saved window state, logs and the `Surffish Safe Storage` keychain item. It asks y/N first; `--yes` skips that. Only those exact paths are touched (#268)

## Changed
- The npm README is now just for people running Surffish (usage, verification, uninstall). Publishing and development notes for the launcher moved to `packages/cli/DEVELOPING.md` (#268)

## CI
- The release workflow's npm job installs a newer npm into a user prefix instead of the runner's global one, fixing the `EACCES` failure on the npm upgrade step (#267)
- New uninstall tests in the `cli` job (#268)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
