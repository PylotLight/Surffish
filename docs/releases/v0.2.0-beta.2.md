# Surffish v0.2.0-beta.2

Surffish recovers its SOCKS5 tunnel after sleep or a network drop, leaves pinch-zoomed pages to two-finger panning, and moves to Electron 46.0.0-alpha.2, alongside the earlier settings-search and display-scale improvements.

## New

- **Settings search**: searches for “translate” and “translation” surface the Languages page and its Target language control, while compact layouts keep Settings navigation usable (#306)

## Fixed

- **Managed tunnel reconnect**: the built-in client and system OpenSSH rebuild the SOCKS5 tunnel themselves after a failure. Network-level errors (connection resets, timeouts, an unreachable host, a dropped link, an unready SSH agent) retry on a one-to-thirty-second backoff, and the tunnel also rebuilds on wake from sleep, so a session killed by sleep recovers without re-saving Settings; Settings shows “Reconnecting to SSH server…” with the last error while an attempt is pending (#312)
- **Pinch-zoom swipes**: back/forward swipes are refused while a page’s visual viewport is zoomed past 1×, so panning a magnified page with two fingers no longer navigates history at random; pinching back out restores swipes. Browser zoom, which reflows rather than pans, is untouched
- **Capture scaling**: screenshot crops, tab thumbnails, sidebar backdrops, and wake-snapshot limits preserve the right bitmap scale on 1×, Retina, and fractional-scale displays (#304)
- **Page drag regions**: browser tabs and Glance no longer receive an obsolete page-level no-drag override; Electron 46 now handles draggable regions in child web contents (#305)

## CI

- Browser tab shortcuts, sidebar chrome, and mini-window native menus are split into focused modules, with regression tests and Electron smoke coverage (#308, #309, #310)
- Compatible project dependencies are refreshed (#311); Electron moves from 46.0.0-alpha.1 to 46.0.0-alpha.2
- A git pre-commit hook formats staged files with bun fmt, so an unformatted file no longer reaches the repository to fail the CI format check

## Packaging

- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
- A rebuild of this release was published as `Surffish-0.2.0-beta.2-2-mac-arm64.zip` (the Homebrew Cask installs it) with the fixes above; the original zip remains on the release, because the published npm launcher package pins its checksum
