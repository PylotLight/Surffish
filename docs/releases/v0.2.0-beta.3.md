# Surffish v0.2.0-beta.3

Surffish keeps Bramble autofill working with Bramble 1.33 and later, smooths sidebar transitions, hides the title bar in fullscreen, and moves to Electron 46.0.0-alpha.7.

## Fixed

- **Bramble autofill**: Bramble 1.33.0 and 1.34.0 builds stage again instead of being refused with "unsupported autofill click guard"; the picker settle delay adapter recognises Bramble's new inlined guard as well as the older form (#316)
- **Update badge**: choosing **Remind Later** no longer lets a stale startup update check bring the badge back (#317)
- **Fullscreen title bar**: the browser title bar stays hidden in fullscreen until the pointer reaches the top edge (#315)
- **Sidebar rail and panels**: the persistent rail and panel layout transition more smoothly between views
- **Managed SSH tunnels**: reconnect after sleep or network drops
- **Pinch-zoom panning**: no longer triggers browser-history navigation
- **Ad filtering and background tabs**: improve resource/cache handling and ordering
- **Toolbar and windows**: improve toolbar and window behavior

## CI

- CI falls back to GitHub-hosted runners when the self-hosted runners are offline (#314)
- Timing-sensitive smoke checks (site-actions menu, mini-window throw, New Tab rail wakeups) tolerate slower hosted runners (#317)
- Compatible dependencies are refreshed; Electron updates to `46.0.0-alpha.7` (#317), and the built-in PDF engine updates to `6.5.438`
- Read Aloud sentence-highlight coverage exercises Electron's user-origin CSS cleanup fix

## Packaging

- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
