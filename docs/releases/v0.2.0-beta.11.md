# Surffish v0.2.0-beta.11

TorBox login now runs in native WebKit on macOS when Chromium's challenge fails, with Bramble autofill and the resulting session imported back into the browser tab.

## New

- **WebKit TorBox login**: opening the TorBox login page or clicking its Login button opens a native WebKit window. The window includes **Fill from Bramble** (⇧⌘L) for saved credentials, and **Done — import session** returns the site session to Surffish.
- **Automatic login hand-off**: the helper opens from a typed login address, from the Login button, and again on later visits while no TorBox session exists. Cookies and the site's local storage are imported into the tab's own session, including tabs in a Space.

## Fixed

- TorBox login no longer stalls on a Cloudflare Turnstile challenge that Chromium rejects. The login completes in WebKit and the tab reloads signed in.
- Imported TorBox cookies are written as domain cookies and the site's local storage is applied to the correct origin, so the browser tab receives the session.
- Bramble's pop-out no longer logs an error when its popup or options page closes it; only Bramble's background host relays the close.
- Tab listener-limit and unknown-permission warnings no longer appear during normal browsing and Bramble staging.

## CI

- Updated the runtime to Electron 46.0.0-alpha.14 and refreshed compatible dependencies.

## Packaging

- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release.
