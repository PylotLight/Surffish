# Surffish v0.1.9

A toolbar ad-blocker button, a Back/Forward history menu, login popups that work (Disqus, OAuth, 3-D Secure), tabs that sleep on their timer instead of early, sharp wake snapshots that restore scroll position, faster tab switching, crash recovery for the toolbar and sidebar, and a smaller app.

## New
- **Ad-blocker button**: a shield in the toolbar, beside the Reading List, shows how many requests the ad filter blocked on the current page (including its iframes). Its popover has the site's on/off switch, the blocked requests grouped by domain, a **Reload** prompt after a change, and a link to Settings → **This site**. The switch is the same per-site setting as in Settings and applies to new requests straight away (#183)
- **Back/Forward history menu**: hold or right-click Back or Forward to list the tab's previous or next pages (newest first, up to 15) with favicon and title, plus **Show Full History**. Cmd/Ctrl-click or middle-click opens an entry in a new tab. Works in split panes and private tabs (#170)
- **Why a tab is sleeping**: the moon on a sleeping tab now says why on hover, for example "Slept after 1 h in the background" or "Put to sleep early by memory saver". Tabs restored at launch that have not loaded yet show a fainter moon (#185)

## Fixed
- Tabs no longer go to sleep long before the sleep timer on a busy Mac. Memory saver treated macOS's "warning" memory pressure, which a busy Mac can sit at for hours, as low memory and discarded background tabs every 30 seconds. It now also checks how much memory the kernel reports as available, never discards a tab sooner than the sleep timer (or 15 minutes after it was last seen) unless memory is critical, and no longer double counts memory shared between Surffish's processes (#185)
- Wake snapshots are sharp on Retina displays (full device resolution, higher quality) instead of blurry and hard to read (#186)
- Waking a sleeping tab now returns to the same scroll position and form contents, keeps its Back/Forward history, and loads from the cache like Back, so the page appears sooner (#186)
- Sign-in popups now open: Disqus login, OAuth sign-ins and 3-D Secure card checks that open a sized popup after a click get a real popup window connected to the page, instead of silently doing nothing. Popups without a click are still blocked, and ⌘W closes the popup rather than the tab (#182)
- The overlay sidebar's frosted backdrop no longer freezes on an old page, and tab thumbnails, wake snapshots and screenshots no longer hang when a tab is switched away or crashes mid-capture (#175)
- An error in the main process no longer shows a blocking "A JavaScript error occurred" dialog; it is logged and the app keeps running. The toolbar, sidebar and window content reload themselves if they crash or stop responding (instead of leaving a window without a toolbar until restart), a GPU process crash repaints every surface, the page context menu no longer fails on some right-clicks, and quitting no longer hangs on a stuck network service (#174)
- A crashing extension background page is reloaded at most 3 times a minute instead of every second indefinitely (#179)

## Performance
- Faster tab switching: leaving a tab reuses its last picture when nothing on the page changed (about 15 → 5 ms of main-thread work per switch), tabs that can never sleep skip the wake snapshot, and the picture for the tab being left is encoded after the new tab has painted (#176, #180, #186)
- Resting the pointer on a sleeping tab in the sidebar opens a connection to its site ahead of the click (#186)
- Extensions with declarativeNetRequest rules: each request is matched once instead of up to three times (#178)
- Smaller app: app.asar ships only the dependency files that are actually loaded (−1.58 MB), and importing from other browsers uses the built-in SQLite instead of sql.js (−722 KB) (#164, #165)
- The startup compile cache is kept per version and older versions' caches are removed, so it no longer grows by about 1 MB with every update (#167)
- Internal clean-up with no change in behaviour: unused code and IPC removed, ad-filter diagnostics that ran on every request removed, and duplicate file-writing and hostname helpers merged (#166, #168)
- The native WebKit browser prototype has been removed from the repository (#181)

## CI
- New warn-only responsiveness bench rows: main-thread blocks, CPU per tab switch and close, keyboard switching, shell jank and a hang check (#172)
- Window-cycle memory growth in the bench now counts only memory that cannot be reclaimed (#169)
- Six flaky smokes fixed, plus a glance split race (#173, #179)
- New smokes for crash recovery, popups, the ad-blocker button and the history menu; dead-code check (knip) in CI (#166, #170, #174, #182, #183)
- README rewritten as a product page with Mac screenshots and a new tagline, "surf without the noise" (#171, #184)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
