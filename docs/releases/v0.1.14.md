# Surffish v0.1.14

Mini windows can now group together, so a few on one edge no longer leave a pile of separate handles.

## New

- **Mini window grouping**: a new setting in Settings → General → Mini window, also in the Window menu (**Mini Window Grouping**) and ⌘K ("Mini Window Grouping: …"). Switching is live and regroups whatever is open without reloading anything (#206)
- **Tabs** (the default): each mini window holds a tab strip (favicon, title, close; it hides with the header). Popping a tab out adds it to the last mini window you used. Drag a tab out of the strip to split it into its own window; drop a window's header on another one, or tuck it to an edge that already has one, to merge them. Each window gets one edge handle with the active tab's icon and a count, and a **Return All Tabs to Browser** button in the header once it holds two. Tabs you can't see keep playing audio and are never slept or archived (#206)
- **Stack**: each tab keeps its own window, but windows tucked to the same edge share one handle (fanned icons and a count) and slide out together, stacked along the edge. Dragging the first window along the edge moves the whole group; drag one away to take it out, tuck one there to add it (#206)
- **Separate**: one window and one handle per tab, the same as v0.1.13 (#206)
- The 6 mini window cap now counts tabs. Your existing mini window settings carry over and start on Tabs (#206)

## CI

- New `test:electron-mini-window-grouping` smoke test covers settings migration, adding, splitting, merging and returning tabs, the tab cap, stack slide out, drag, add and remove, and live mode switches (#206)

## Packaging
