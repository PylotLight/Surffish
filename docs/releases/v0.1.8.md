# Surffish v0.1.8

Glance link peek, faster-feeling browsing (preconnect and wake snapshots for sleeping tabs), lighter ad-filter injection, Cloudflare challenges that pass, plain http LAN devices that open, and Bramble quick unlock that survives restarts.

## New
- **Glance**: Shift+click a link (or right-click → **Open Link in Glance**, or ⌘K → **Open Copied Link in Glance**) to open it in a sheet over the current tab instead of a new tab. Esc, ⌘W or a click on the backdrop closes it, ⌘/Ctrl+Enter or **Open as Tab** turns it into a real tab right after the current one (no reload, history kept), and **Split View** opens it beside the current tab. It loads in the source tab's session, so private tabs, Spaces and per-site proxy rules apply. The Shift+click part can be turned off in Settings → **General → Glance** (#156)
- **Preload pages for faster browsing**: while typing in the address bar (~150 ms after the last key) and when resting on a link (~200 ms, including links inside a Glance), Surffish opens one connection to the likely next site so the page starts sooner. Origin only, never the search text; never from private tabs or while the kill switch is blocking. On by default, toggle in Settings → **General → Tabs** (#155)
- **Wake snapshots**: a sleeping or discarded tab shows its last picture straight away while the real page reloads underneath, then fades out once the page paints. Clicks and scrolls go straight to the page. Kept in memory only (never on disk), 24 MB cap (#155)
- **Bramble quick unlock survives restarts by default**: the PIN and Touch ID keep working after Surffish restarts (device key protected by the macOS Keychain). "Require master password after Surffish restarts" is now a switch in Settings → **Integrations**; turning it on asks for the PIN. Surffish's own master password screen is gone, so only Bramble's form ever shows when the PIN isn't armed. Older memory-only setups switch over the next time they unlock (#154)

## Fixed
- Cloudflare challenges ("Checking your browser" / Turnstile, e.g. steamdb.info) now pass. Cross-site frames and service workers were still getting an Electron user agent; every page, frame, worker and request now sends the same reduced Chrome user agent (#160)
- Typing a LAN address like `192.168.1.10` now opens it over plain http instead of forcing https and failing with `ERR_SSL_PROTOCOL_ERROR`. Local https failures offer **Continue to http://** on the error page, typed public hosts that fail over https offer **Continue to HTTP**, and error pages no longer show a lock (#161)
- Toolbar icons on the right side are all one size now (Downloads was huge until its panel was first opened), and Bramble no longer sits in a permanent green pill (#153)
- The toolbar logo's hidden animation: the fish now swims nose first, fades through the ring's gaps and the scene fills the window under the traffic lights (#158)

## Performance
- Ad filter: scriptlets are bundled per frame so shared uBO helpers go in once (a YouTube frame drops from ~293 KB to ~56 KB of injected script), frame payloads are cached per hostname, and no DOM observer runs where generic hiding is off (#162)
- Glance, preconnect and wake snapshots load lazily and add nothing at launch (#155, #156)

## CI
- The perf check now splits cold start into phases (main loaded, Electron ready, profile ready, window, toolbar, New Tab, deferred ad filter/extensions) plus warm-profile starts, all warn-only. `bun run perf --trace` records a local startup trace. A V8 code cache for the shell views was tried and dropped: it hit but wasn't faster than `file://` (#157)
- New warn-only bench rows for renderers/memory across mixed sites and ad-filter cosmetics cost per navigation (#162)
- New smokes for Glance, preconnect + wake snapshots and the user agent (#155, #156, #160)

## Packaging
- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
