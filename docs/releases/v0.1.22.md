# Surffish v0.1.22

A steadier menu bar popout: the mini window header no longer flashes. Its bar is now fully opaque, and the loading line only tracks the page itself, not hidden frames. Plus an opt-in header event log for chasing anything left. Ships on Electron 45.0.0-beta.5.

> This release ships on an Electron **beta** (45.0.0-beta.5). Main tracks Electron betas; a daily check opens a bump PR when a new one is out.

## Fixed

- **Menu bar popout header flash**: the header bar is now opaque. The 94 % opaque bar on a transparent window let macOS compositing flash through it (#255)
- **Popout loading line**: only follows the main page load, so hidden iframe loads (ads, trackers, embeds) on an idle page no longer blink it (#255)

## Development

- Opt-in mini window header event log: run with `SURFFISH_DEBUG_HEADER=1`, or ⌘K → **Start Logging Mini Window Header Events** (#255)

## Packaging

- Apple silicon zip only, unsigned and not notarized. If macOS reports the app is damaged, run `xattr -cr /Applications/Surffish.app` on a copy downloaded from the official release
